# DIBS 2026 announcement — editable post

1. Put a BOATELLI source photo next to `post.html` as `photo.jpg` (unchanged, no AI edits).
2. Open `post.html` in a browser — text is editable by clicking. Crop: `--photo-x` / `--photo-y` in the CSS.
   `post.html?story` — 9:16 story version.
3. `node render.js` → `export/post-1080x1350.png` and `export/story-1080x1920.png`.
Caption & hashtags: `caption.md`.
